# Demography Daily Digest

- **Версия:** v1.0
- **Владелец:** Tatiana
- **Теги:** demography, news, digest, research

## Цель

Ежедневный поиск и отбор значимых новостей по демографии РФ с подготовкой краткого дайджеста, готового к публикации.

## Входные данные

| Переменная | Описание |
|---|---|
| `{date}` | Дата, за которую готовится дайджест |
| `{time_range}` | Временной интервал поиска материалов |
| `{geo_scope}` | Географический охват (по умолчанию — федеральный уровень РФ) |
| `{topics}` | Темы поиска, например рождаемость, меры поддержки семей, выплаты, семейная политика, репродуктивное здоровье |
| `{sources}` | Список приоритетных источников |
| `{max_length}` | Максимальный объем итогового текста |

## Выходной формат

Простой текст без Markdown, таблиц и эмодзи: блок «ГЛАВНОЕ ЗА ДЕНЬ» с пронумерованными событиями (заголовок + краткое описание, что произошло и почему это важно). Объем не превышает `{max_length}`. Если значимых новостей нет, дайджест прямо сообщает об этом.
