# Тест-кейсы: Demography Daily Digest v1.0

Промпт: [../prompts/demography_daily_digest.md](../prompts/demography_daily_digest.md)

## Тест 1. Обычный день с несколькими значимыми федеральными новостями

**Входные переменные**

- `{date}`: 01.10.2026
- `{time_range}`: 00:00–23:59 МСК 01.10.2026
- `{geo_scope}`: Россия, федеральный уровень
- `{topics}`: рождаемость, меры поддержки семей, выплаты, семейная политика, репродуктивное здоровье
- `{sources}`: publication.pravo.gov.ru, sozd.duma.gov.ru, rosstat.gov.ru, government.ru, ТАСС, Интерфакс
- `{max_length}`: 2000 знаков

**Что проверить**

- События упорядочены по приоритету (например, подписанный закон выше новой статистики, статистика выше внесенного законопроекта).
- Все события относятся к 01.10.2026; даты публикации и события сверены.
- Публикации об одном событии из разных источников объединены в один пункт.
- В каждом пункте есть заголовок и объяснение, почему событие важно.
- Нет Markdown, таблиц, эмодзи; объем не превышает 2000 знаков.

**Ожидаемый результат**

Текст, начинающийся с «ГЛАВНОЕ ЗА ДЕНЬ», с 3–5 пронумерованными федеральными событиями в порядке приоритета, без дублей и устаревших материалов, готовый к публикации.

## Тест 2. Много региональных и дублирующихся публикаций, мало федерально значимых событий

**Входные переменные**

- `{date}`: 05.10.2026
- `{time_range}`: 00:00–23:59 МСК 05.10.2026
- `{geo_scope}`: Россия, федеральный уровень; региональные новости — только с федеральным значением
- `{topics}`: рождаемость, демографическая политика, меры поддержки семей
- `{sources}`: government.ru, rosstat.gov.ru, ТАСС, РИА Новости, региональные СМИ
- `{max_length}`: 1500 знаков

**Что проверить**

- Локальные региональные новости (например, вручение подарков новорожденным в отдельном городе) исключены.
- Региональная новость включена только если это пилотный проект с перспективой масштабирования, событие федерального значения или инициатива крупной федеральной компании.
- Многочисленные перепечатки одного федерального события сведены в один пункт.
- Экспертные комментарии без нового факта исключены.
- Объем не превышает 1500 знаков.

**Ожидаемый результат**

Короткий дайджест «ГЛАВНОЕ ЗА ДЕНЬ» с 1–2 пунктами: только федерально значимые события (и, при наличии, региональный пилот с перспективой масштабирования). Нет дублей и локальных малозначимых новостей; число пунктов не раздуто ради количества.

## Тест 3. День без значимых новостей

**Входные переменные**

- `{date}`: 11.10.2026
- `{time_range}`: 00:00–23:59 МСК 11.10.2026 (выходной день)
- `{geo_scope}`: Россия, федеральный уровень
- `{topics}`: рождаемость, меры поддержки семей, выплаты, семейная политика, репродуктивное здоровье
- `{sources}`: publication.pravo.gov.ru, sozd.duma.gov.ru, rosstat.gov.ru, government.ru, ТАСС
- `{max_length}`: 2000 знаков

**Что проверить**

- В дайджест не попали старые новости, перепечатки материалов прошлых дней, реклама и экспертные мнения без нового факта.
- Модель не выдумывает события и не добавляет слабые новости ради заполнения.
- Нет Markdown, таблиц, эмодзи.

**Ожидаемый результат**

Текст вида:

```text
ГЛАВНОЕ ЗА ДЕНЬ

За 11.10.2026 значимых событий в сфере демографии РФ не выявлено.
```
